# Little Agents — AI Virtual Office 🤖

An interactive AI-powered virtual office where animated characters represent real AI agents performing tasks using locally hosted large language models.

## Features
- **Pixel — Developer Agent:** Generates code and creates development files.
- **Nova — Research Agent:** Performs research and generates reports.
- **Byte — Data Agent:** Analyzes CSV data and produces summaries.
- **Animated Virtual Office:** Characters move and react according to agent activity.
- **Local AI Integration:** Powered by Ollama with Qwen2.5 3B.
- **No Paid API Required:** Run AI models locally without API usage fees.

## Tech Stack
- **Frontend:** React, Vite, Phaser
- **Backend:** Node.js
- **AI Model:** Qwen2.5 3B
- **AI Runtime:** Ollama

## Project Goal
To explore AI agent automation by combining task execution, local language models, and interactive game-style visualization into one application.
